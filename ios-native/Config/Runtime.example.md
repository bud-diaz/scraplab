# Native iOS local runtime config

Copy this file to a local ignored xcconfig or set these three values in your Xcode build settings before installing a real-auth build.

```xcconfig
SCRAPLAB_SUPABASE_URL = https:/$()/YOUR_PROJECT.supabase.co
SCRAPLAB_SUPABASE_ANON_KEY = YOUR_SUPABASE_ANON_KEY
SCRAPLAB_REVENUECAT_IOS_API_KEY = <YOUR_REVENUECAT_PUBLIC_IOS_KEY>
```

Notes:

- These are public client-side keys, but do not commit real project values from local builds.
- The Supabase URL uses `https:/$()/...` because raw `//` starts a comment in `.xcconfig` files; Xcode expands this back to `https://...` at build time.
- The app reads them from `Info.plist` keys generated by `project.yml`:
  - `ScrapLabSupabaseURL`
  - `ScrapLabSupabaseAnonKey`
  - `ScrapLabRevenueCatIOSAPIKey`
- If any value is blank, the native app safely falls back to the unconfigured service and shows a human-readable setup error instead of simulating auth or purchases.
